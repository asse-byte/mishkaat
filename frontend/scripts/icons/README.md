# توليد أيقونات المشكاة

كل الأيقونات في `public/icons/` مولَّدة من مصدر واحد: `mark.js`. لا تُحرَّر صور
PNG يدوياً — تُعدَّل العلامة هنا ثم يُعاد التوليد، وإلا تباعدت المقاسات عن بعضها.

## البنية

| الملف | ما فيه |
|---|---|
| `mark.js` | العلامة المتّجهة: قوس مدبَّب متساوي الأضلاع + قنديل معلَّق، بثلاث خلفيات (مستديرة / سابغة / شفّافة) |
| `build.js` | كل مقاسات PNG + `favicon.ico` + أيقونة iOS |
| `og.js` | بطاقة معاينة الروابط 1200×630 (النصّ العربي عبر Pango داخل sharp) |

## التشغيل

`sharp` ليست من تبعيات المشروع عمداً: تُستعمل مرّة عند تغيير الهوية، لا في كل
بناء، وحجمها ~10 ميغابايت. تُثبَّت عند الحاجة فقط:

```bash
cd frontend && npm i --no-save sharp
node scripts/icons/build.js public
node scripts/icons/og.js public
```

## قواعد لا تُخالَف

1. **الرسم داخل دائرة نصف قطرها 204 من مركز مربّع 512.** هذه هي «المنطقة الآمنة»
   لأيقونات `maskable`: أندرويد يقصّ الأيقونة بقناع لا نعرفه مسبقاً (دائرة، مربّع
   مستدير، سداسي)، وما خرج عن الدائرة يُقصّ. الرسم الحالي أقصى بعد فيه ≈182.
2. **`purpose: "any"` و`"maskable"` ملفّان منفصلان، لا ملفّ واحد بالغرضين.**
   أيقونة `any` تحمل حوافّها المستديرة بنفسها؛ لو أُعلنت `maskable` أيضاً قصّها
   أندرويد مرّة ثانية فوق استدارتها.
3. **أيقونة iOS سابغة ومعتمة.** iOS يفرض قناعه الخاص ولا يفهم الشفافية: أيقونة
   بحوافّ مستديرة مسبقاً تظهر باستدارة مزدوجة وحافّة داكنة حولها.
4. **عند تغيير أيّ أيقونة يُرفع رقم `CACHE_NAME` في `public/sw.js`.** عامل الخدمة
   يخزّن الأيقونات، فبدون رفع الرقم تبقى الأجهزة المثبَّتة على القديم.
