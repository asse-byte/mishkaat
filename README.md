نظام متكامل لإدارة مراكز تحفيظ القرآن الكريم، يشمل إدارة المحفظين، الطلاب، الحلقات، الحضور، التسميع، المالية، والتقارير — مع دعم كامل لصلاحيات متعددة المستويات.

## ⚙️ متطلبات التشغيل

| المتطلب | الإصدار الموصى به | الرابط |
|--------|-----------------|--------|
| **Node.js** | 18+ | https://nodejs.org |
| **Python** | 3.9+ | https://python.org |
| **MongoDB** | 6+ | https://www.mongodb.com |

> تأكد من أن MongoDB يعمل على المنفذ الافتراضي `27017` قبل تشغيل النظام.

## 🚀 طريقة التشغيل

### الخطوة 1 — تشغيل الخادم الخلفي (Backend)

افتح Terminal وشغّل الأوامر التالية:

```bash
cd backend
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8001 --reload
```

✅ الخادم يعمل على: **`http://localhost:8001`**

> في أول تشغيل، يقوم الخادم تلقائياً بإنشاء جميع الحسابات والبيانات الافتراضية في قاعدة البيانات.

---

### الخطوة 2 — تشغيل الواجهة الأمامية (Frontend)

افتح Terminal **جديد** وشغّل الأوامر التالية:

```bash
cd frontend
npm install
npm run dev
```

✅ الواجهة تعمل على: **`http://localhost:3000`**

> البروكسي مضبوط تلقائياً للتواصل مع الخادم الخلفي على المنفذ 8001.

## 📲 تثبيت التطبيق على الأجهزة

المشكاة تطبيق ويب قابل للتثبيت (PWA): يُثبَّت من المتصفّح مباشرة بلا متجر
تطبيقات، ويعمل بعدها كتطبيق مستقلّ بأيقونته واسمه بلا شريط عنوان.

| الجهاز | الطريقة | ما يظهر |
|---|---|---|
| **أندرويد** (كروم) | القائمة ⋮ ← «تثبيت التطبيق» | **المشكاة** تحت الأيقونة |
| **آيفون / آيباد** (سفاري) | زرّ المشاركة ← «إضافة إلى الشاشة الرئيسية» | **المشكاة** تحت الأيقونة |
| **حاسوب** (كروم/إيدج) | أيقونة التثبيت في شريط العنوان | نافذة مستقلّة باسم التطبيق |

**شرط أساسي: HTTPS.** المتصفّحات لا تعرض خيار التثبيت إلا على اتصال آمن
(أو `localhost` للتطوير). لن يظهر الخيار على `http://` عادي.

### تفاصيل تخصّ الأجهزة

- **الاسم المعروض** يأتي من `short_name` في `frontend/public/manifest.json`
  على أندرويد وسطح المكتب، ومن `apple-mobile-web-app-title` في `index.html`
  على iOS. **إن غُيّر أحدهما فليُغيّر الآخر معه** وإلا اختلف الاسم بين جهاز وآخر.
- **الأيقونات** كلها مولَّدة من مصدر متّجه واحد — انظر
  [`frontend/scripts/icons/README.md`](frontend/scripts/icons/README.md).
  عند تغيير أيّ أيقونة **يُرفع رقم `CACHE_NAME` في `public/sw.js`**، وإلا بقيت
  الأجهزة المثبَّتة على الأيقونة القديمة.
- **iOS يعرض ~12 محرفاً** تحت الأيقونة ثم يقصّ الباقي بثلاث نقاط؛ لهذا
  `apple-mobile-web-app-title` هو «المشكاة» وحدها لا الاسم الكامل.
- **الوضع الليلي** يتبع إعداد الجهاز تلقائياً، ويمكن قلبه من داخل التطبيق.

### إن ظهرت الأيقونة أو الاسم القديم بعد التحديث

عامل الخدمة يخزّن الأصول محلياً. على الجهاز: احذف التطبيق المثبَّت، ثم امسح
بيانات الموقع من إعدادات المتصفّح، ثم أعد التثبيت.
