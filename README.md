نظام متكامل لإدارة مراكز تحفيظ القرآن الكريم، يشمل إدارة المحفظين، الطلاب، الحلقات، الحضور، التسميع، المالية، والتقارير — مع دعم كامل لصلاحيات متعددة المستويات.

---

## ⚙️ متطلبات التشغيل

| المتطلب | الإصدار الموصى به | الرابط |
|--------|-----------------|--------|
| **Node.js** | 18+ | https://nodejs.org |
| **Python** | 3.9+ | https://python.org |
| **MongoDB** | 6+ | https://www.mongodb.com |

> تأكد من أن MongoDB يعمل على المنفذ الافتراضي `27017` قبل تشغيل النظام.

---

## 🚀 طريقة التشغيل

### الخطوة 1 — تشغيل الخادم الخلفي (Backend)

افتح Terminal وشغّل الأوامر التالية:

```bash
cd backend
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8001 --reload
```

✅ الخادم يعمل على: **`http://localhost:8001`**

> في أول تشغيل، يقوم الخادم تلقائياً بإنشاء جميع الحسابات والبيانات الافتراضية في قاعدة البيانات.

---

### الخطوة 2 — تشغيل الواجهة الأمامية (Frontend)

افتح Terminal **جديد** وشغّل الأوامر التالية:

```bash
cd frontend
npm install
npm run dev
```

✅ الواجهة تعمل على: **`http://localhost:3000`**

> البروكسي مضبوط تلقائياً للتواصل مع الخادم الخلفي على المنفذ 8001.

## 🔐 بيانات تسجيل الدخول

> هذه بيانات بيئة التطوير فقط. **يجب تغيير كلمات المرور قبل النشر الرسمي.**

| الدور | اسم المستخدم | كلمة المرور | الصلاحيات |
|-------|-------------|-------------|-----------|
| **مدير النظام** | `admin` | `admin123` | إدارة كاملة لجميع المراكز والحسابات |
| **مدير المركز** | `manager1` | `manager123` | إدارة المحفظين والطلاب والتقارير والمالية |
| **محفظ / معلم** | `teacher1` | `teacher123` | تسجيل الحضور والتسميع لطلاب حلقته |
| **طالب** | `student1` | `student123` | عرض تقدمه الشخصي في الحفظ |
| **ولي الأمر** | `parent1` | `parent123` | متابعة تقدم أبنائه والرسوم |

## 🎯 الميزات الرئيسية

- **نظام صلاحيات متعدد المستويات** — 5 أدوار مختلفة بصلاحيات مخصصة
- **إدارة المراكز** — تسجيل، بحث، تعديل، حذف
- **إدارة المحفظين والطلاب** — ملفات كاملة مع نقل الحلقات
- **الحضور والغياب** — تسجيل يومي ومراقبة إحصائية
- **التسميع** — تقييم أداء الطلاب بمعايير واضحة
- **المالية** — رسوم الطلاب، رواتب المحفظين، المصروفات (FCFA)
- **التقارير** — تقارير شاملة قابلة للطباعة لمدير المركز
- **لوحات تحكم مخصصة** — واجهة مميزة لكل دور
